AIQuota 2.0

AIQuotaがiPhoneとiPadに登場。

  • iPhoneとiPad向けのAIQuota。CodexとClaudeを二重リングのカードで表示し、リセット時刻、プランの詳細、最終更新時刻もわかります。
  • ホーム画面とロック画面のウィジェット。「アカウント」と「アカウント一覧」ウィジェットを小・中・大サイズで、2行の大サイズのレイアウト、カスタマイズできるロック画面ウィジェットも用意しました。
  • Macアプリを刷新。個人用と仕事用のアカウントを並べ替え可能なカードで表示し、メニューバーに出すゲージも選べます。
  • Codexの使用履歴。Codexカードに1日の使用量を表示し、詳細ではモデル別、アプリ別の内訳も確認できます。
  • Codexのリセットのお知らせ。Codex Resetsが発表を伝えると、閉じることのできるお知らせを表示します。
  • あらゆる使用枠に対応。月単位や週単位のみのプランは、7日や30日など枠の名前を付けた1つのゲージで表示し、提供されない枠は表示しません。
  • しきい値での通知。設定したレベルで枠ごとに1回通知し、リセットのリマインダーも選べます。
  • デモを試す。iPhoneとiPadで、サインインせずにサンプルの使用量を確認できます。

またはMac版2.0を直接ダウンロード。

バージョン 1.9.28
