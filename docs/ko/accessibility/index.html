손쉬운 사용

최종 업데이트: 2026년 4월 7일

이 번역은 참고용으로 제공됩니다. 영어 원문과 다른 경우 영어 원문이 우선합니다.

AIQuota는 macOS와 웹에서 쉽게 사용할 수 있는 것을 목표로 합니다. 손쉬운 사용은 제품과 사이트를 설계하고 업데이트하는 과정에 꾸준히 반영됩니다.

손쉬운 사용에 대한 접근 방식

읽기 쉬운 글꼴, 잘 보이는 포커스 상태, 읽기 좋은 색상 대비, 키보드 접근, 시스템 설정을 따르는 동작을 지원하려고 노력합니다.

웹사이트

AIQuota 사이트는 단순하고 의미에 맞는 HTML과 가벼운 CSS, JavaScript로 만들어졌습니다. 상호작용 요소는 키보드로 접근할 수 있도록 했으며, 상단 동영상은 동작 줄이기 설정을 따릅니다.

앱

AIQuota는 중요한 상태를 한눈에 보여 주면서도 앱 안에서 더 자세한 정보를 확인할 수 있도록 설계되었습니다. 메뉴 막대, 팝오버, 위젯을 이해하기 쉽고 안정적으로 만드는 것을 목표로 합니다.

지속적인 노력

손쉬운 사용은 지속적인 노력이 필요한 일이며, 일부 영역은 아직 모든 기기, 설정, 보조 기술 조합에서 완벽하게 작동하지 않을 수 있습니다.

피드백

손쉬운 사용 문제가 있거나 AIQuota 사용에 도움이 필요하면 help@aiquota.app로 이메일을 보내 주세요.
