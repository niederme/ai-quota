개인정보 처리방침

최종 업데이트: 2026년 4월 17일

이 번역은 참고용으로 제공됩니다. 영어 원문과 다른 경우 영어 원문이 우선합니다.

AIQuota는 Codex와 Claude Code 사용량을 확인하도록 돕는 네이티브 macOS 앱입니다. 이 방침은 AIQuota가 저장하는 정보, 읽는 정보, 기기 밖으로 전송되는 정보를 설명합니다.

AIQuota가 접근하는 정보

연결하는 서비스에 따라 AIQuota는 다음 정보에 접근할 수 있습니다.

  • Codex 사용량 데이터를 읽는 데 사용되는 OpenAI 세션 정보.
  • Claude Code 사용량 데이터를 읽는 데 사용되는 Anthropic 또는 Claude 세션 정보.
  • 사용 기간, 초기화 시간, 요금제 이름, 크레딧 등 사용량과 관련된 계정 세부 정보.
  • 앱 안에서 선택한 알림 설정과 화면 설정.

정보의 사용 방법

AIQuota는 이 정보를 앱의 핵심 기능을 제공하는 데만 사용합니다.

  • 메뉴 막대와 위젯에 현재 사용량 상태 표시.
  • 초기화 시간, 경고 상태, 요금제 세부 사항 표시.
  • 사용량이 부족하거나 위험 수준이거나 초기화되었을 때 선택적 알림 전송.
  • 앱을 다시 실행할 때 연결된 서비스와 설정 복원.

AIQuota는 광고, 프로파일링, 분석 데이터 재판매, 마케팅 어트리뷰션에 데이터를 사용하지 않습니다.

선택적 익명 분석

AIQuota에는 ‘익명 사용 데이터 공유’라는 선택 설정이 있습니다. 이 설정은 기본적으로 꺼져 있습니다.

이 설정을 켜면 AIQuota는 앱 실행, 일일 활성 사용, 앱 버전, 서비스 연결, 설정 완료 같은 간단한 익명 제품 지표를 보냅니다. 이 이벤트는 Google Firebase Analytics에서 처리될 수 있습니다. 프롬프트, 인증 토큰, 쿠키 또는 개인정보는 포함되지 않습니다.

데이터 저장 위치

AIQuota는 가능한 한 데이터를 기기 안에 보관하도록 설계되었습니다.

  • 민감한 세션 정보는 macOS 키체인에 저장됩니다.
  • 앱 설정과 위젯용 상태는 앱의 로컬 저장소 또는 공유 앱 그룹 저장소에 저장될 수 있습니다.
  • 위젯과 빠른 새로 고침을 위해 캐시된 사용량 값이 로컬에 저장될 수 있습니다.

기기 밖으로 전송되는 정보

AIQuota는 사용량 추적을 위한 자체 서버를 운영하지 않습니다.

AIQuota가 상태를 새로 고칠 때 요청은 기기에서 연결한 서비스로 직접 전송됩니다. 예를 들어 사용량 관련 계정 데이터를 가져오는 데 필요한 OpenAI 또는 Anthropic 엔드포인트입니다.

제3자

AIQuota는 앱을 제공하는 데 필요한 경우에만 다음 제3자 서비스를 이용합니다.

  • OpenAI: Codex 사용량 추적을 연결한 경우.
  • Anthropic: Claude Code 사용량 추적을 연결한 경우.
  • Google Firebase Analytics: 익명 사용 분석에 동의한 경우에만.
  • 앱, 위젯, 알림, 로컬 보안 저장소를 실행하는 데 사용되는 Apple 플랫폼 서비스.

보안

AIQuota는 키체인 저장소와 해당하는 경우 HTTPS 요청 등 플랫폼이 제공하는 보안 기능을 사용합니다. 완벽한 저장 또는 전송 방법은 없지만, 이 앱은 불필요한 데이터 처리를 최소화하고 AIQuota가 운영하는 별도의 서버를 두지 않도록 설계되었습니다.

사용자의 선택

  • 앱 안에서 서비스 연결을 해제할 수 있습니다.
  • 언제든지 알림을 끌 수 있습니다.
  • 익명 분석을 끈 상태로 두거나 나중에 설정에서 변경할 수 있습니다.
  • Mac에서 앱과 로컬 데이터를 삭제할 수 있습니다.

이 방침의 변경

이 개인정보 처리방침은 AIQuota의 변경에 따라 업데이트될 수 있습니다. 이 페이지 상단의 날짜는 최신 개정일을 나타냅니다.
