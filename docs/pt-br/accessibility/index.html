Acessibilidade

Última atualização: 7 de abril de 2026

Esta tradução é oferecida apenas como referência. Em caso de divergência, prevalece a versão em inglês.

O AIQuota quer ser simples de usar no macOS e na web. A acessibilidade faz parte contínua de como o produto e o site são projetados e atualizados.

Como tratamos a acessibilidade

Procuramos oferecer texto claro, estados de foco visíveis, contraste de cores legível, acesso pelo teclado e animações que respeitam as preferências do sistema.

O site

O site do AIQuota é feito em HTML semântico simples, com CSS e JavaScript leves. Os elementos interativos foram pensados para ser acessíveis pelo teclado, e o vídeo de abertura respeita a preferência de reduzir o movimento.

O app

O AIQuota foi projetado para manter o status importante visível num relance e, ao mesmo tempo, oferecer informações mais detalhadas no app. Queremos que a barra de menus, o popover e os widgets sejam compreensíveis e estáveis.

Trabalho contínuo

A acessibilidade é um esforço contínuo, e algumas áreas talvez ainda não funcionem perfeitamente em todas as combinações de dispositivo, ajuste ou tecnologia assistiva.

Feedback

Se encontrar um problema de acessibilidade ou precisar de ajuda para usar o AIQuota, escreva para help@aiquota.app.
