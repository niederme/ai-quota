Confidentiel par nature

Votre connexion reste sur l’appareil.

Les identifiants restent dans le trousseau de l’appareil, partagés uniquement avec les widgets d’AIQuota. Aucune clé d’API, aucun prompt lu, et les statistiques anonymes restent désactivées tant que vous ne les activez pas.
