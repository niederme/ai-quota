Politique de confidentialité

Dernière mise à jour : 17 avril 2026

Cette traduction est fournie à titre indicatif. En cas de divergence, la version anglaise fait foi.

AIQuota est une app macOS native qui vous aide à surveiller vos quotas Codex et Claude Code. Cette politique explique ce qu’AIQuota stocke, ce qu’il lit et ce qui quitte votre appareil.

Ce à quoi AIQuota accède

Selon les services que vous connectez, AIQuota peut accéder :

  • aux informations de votre session OpenAI, utilisées pour lire les données de quota Codex.
  • aux informations de votre session Anthropic ou Claude, utilisées pour lire les données de quota Claude Code.
  • aux détails du compte liés aux quotas, comme les fenêtres d’utilisation, les heures de réinitialisation, les noms de forfaits et les crédits.
  • aux réglages de notification et aux préférences d’interface que vous choisissez dans l’app.

Utilisation de ces informations

AIQuota utilise ces informations uniquement pour fournir les fonctions essentielles de l’app :

  • Afficher l’état actuel de vos quotas dans la barre des menus et les widgets.
  • Afficher les heures de réinitialisation, les niveaux d’alerte et les détails du forfait.
  • Envoyer des notifications facultatives quand le quota est bas, critique ou réinitialisé.
  • Restaurer vos services connectés et vos préférences d’un lancement à l’autre.

AIQuota n’utilise pas vos données pour la publicité, le profilage, la revente de statistiques ou l’attribution marketing.

Statistiques anonymes facultatives

AIQuota propose un réglage facultatif appelé « Partager des données d’utilisation anonymes ». Ce réglage est désactivé par défaut.

Si vous choisissez de l’activer, AIQuota envoie de simples mesures anonymes sur le produit : ouverture de l’app, utilisation active quotidienne, version de l’app, connexion d’un service et fin de la configuration. Ces événements peuvent être traités par Google Firebase Analytics. Ils n’incluent ni prompts, ni jetons d’authentification, ni cookies, ni informations personnelles.

Où les données sont stockées

AIQuota est conçu pour garder les données sur l’appareil autant que possible.

  • Les informations de session sensibles sont stockées dans le trousseau de macOS.
  • Les préférences de l’app et l’état destiné aux widgets peuvent être stockés dans le stockage local de l’app ou dans le stockage partagé du groupe d’apps.
  • Des valeurs de quota en cache peuvent être stockées localement pour les widgets et des actualisations rapides.

Ce qui quitte votre appareil

AIQuota n’exploite pas son propre serveur pour le suivi des quotas.

Quand AIQuota actualise votre état, les requêtes partent directement de votre appareil vers le service que vous avez connecté, par exemple les points de terminaison d’OpenAI ou d’Anthropic nécessaires pour récupérer les données de compte liées aux quotas.

Tiers

AIQuota ne fait appel à des services tiers que lorsque c’est nécessaire au fonctionnement de l’app :

  • OpenAI, quand vous connectez le suivi des quotas Codex.
  • Anthropic, quand vous connectez le suivi des quotas Claude Code.
  • Google Firebase Analytics, uniquement si vous acceptez les statistiques d’utilisation anonymes.
  • Les services de la plateforme Apple utilisés pour l’app, les widgets, les notifications et le stockage local sécurisé.

Sécurité

AIQuota utilise les fonctions de sécurité de la plateforme, comme le stockage dans le trousseau et les requêtes HTTPS le cas échéant. Aucune méthode de stockage ou de transmission n’est parfaite, mais l’app est conçue pour limiter le traitement de données inutile et éviter tout serveur distinct exploité par AIQuota.

Vos choix

  • Vous pouvez déconnecter des services dans l’app.
  • Vous pouvez désactiver les notifications à tout moment.
  • Vous pouvez laisser les statistiques anonymes désactivées, ou changer d’avis plus tard dans les réglages.
  • Vous pouvez supprimer l’app et ses données locales de votre Mac.

Modifications de cette politique

Cette politique de confidentialité peut être mise à jour à mesure qu’AIQuota évolue. La date en haut de cette page indique la dernière révision.

Contact
